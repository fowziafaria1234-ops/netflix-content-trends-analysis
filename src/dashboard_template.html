      Method & data quality

      How the numbers were produced, and what is missing in the source data

      Load & audit7,787 rows from the Kaggle Netflix titles extract. Missing values measured for every column before any change.
      CleanWhitespace trimmed, date_added parsed, missing country/director labelled “Unknown” rather than dropped.
      Engineer featuresRuntime split into minutes (films) and seasons (TV), ratings mapped to audience bands, genres and countries exploded to one row each.
      Aggregate & testYearly, genre, country and rating metrics built with Pandas; unit tests reconcile every total back to the raw row count.
